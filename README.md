## 🛠️ التقنيات المستخدمة

- **الإطار:** [Astro v5](https://astro.build/) (Static Site Generation - SSG فائق السرعة)
- **التصميم:** [Tailwind CSS v4](https://tailwindcss.com/)
- **الخطوط:** Cairo, IBM Plex Sans Arabic, JetBrains Mono
- **الاستضافة:** [Cloudflare Pages](https://pages.cloudflare.com/)

## 💻 التشغيل المحلي والتطوير

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء النسخة النهائية للنشر
npm run build
```
